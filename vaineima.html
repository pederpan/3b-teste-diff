O que é este site?

Este é um exemplo estruturado de um site "qualquer". Ele utiliza HTML para a estrutura e CSS para o visual.

Principais elementos incluídos:

  • Header: O cabeçalho com o título.
  • Nav: Menu de navegação simples.
  • Container: Onde o conteúdo principal reside.
  • Footer: O rodapé da página.

Você pode editar este arquivo em qualquer bloco de notas ou editor de código (como o VS Code) para começar a criar sua própria página web.
